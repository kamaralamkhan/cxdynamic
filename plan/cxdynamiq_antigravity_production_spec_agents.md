## 5. MANDATORY WORKFLOW DIAGRAMS TO BUILD IN CODE (CLIENT BRIEF SECTIONS 5 & 6)

### Diagram A: Dedicated Agentic AI Section (Brief Section 5)
Create a dedicated interactive section explaining how CXdynamIQ's **Agentic AI** moves beyond rigid, rule-based chatbot/voicebot decision trees to autonomous goal execution across this exact 5-stage pipeline:
> **`Understand` → `Reason` → `Act` → `Resolve` → `Learn`**

- **Interactive Example Flow to Render in UI**:
  1. **Understand**: Customer messages on WhatsApp or calls via Voice (*"My shipment hasn't arrived and I need to update my delivery address"*); AI detects intent, urgency, and sentiment.
  2. **Reason**: Agentic AI checks identity verification status, queries the Logistics ERP/CRM via API, and evaluates policy rules in real time.
  3. **Act**: AI autonomously updates the delivery address in the backend order system and triggers a rescheduled courier slot via webhook.
  4. **Resolve**: AI confirms the updated delivery window with the customer on WhatsApp/Voice and sends an automated confirmation receipt.
  5. **Learn**: Interaction outcome, CSAT signal, and transcript feed into Conversation Intelligence to refine future accuracy.

### Diagram B: Human + AI Collaboration Journey (Brief Section 6)
Never position AI as "replacing agents." Explicitly feature this core positioning banner:
> **"AI handles automation and repetitive interactions, while human agents handle complex, sensitive and high-value conversations."**

Below the banner, render an interactive 6-stage horizontal architecture diagram showing the complete lifecycle:
> **`AI Self-Service` → `AI Agent` → `Human Agent` → `AI Assist` → `Resolution` → `AI QA & Analytics`**
